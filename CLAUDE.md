# GameDap

Personal gaming companion (monorepo). Phase 1 is only the Discord news collector; there is no web app yet.

## Layout
- `collector/`: Python 3.12 package `gamedap_collector`. Run commands from this directory.
  - `config.yaml`: games, their Discord channel ids, and `origin_labels` for forwarded messages (keys still `<PLACEHOLDER>` are ignored).
  - `discord_client.py` (REST only, handles 429), `normalize.py` (pure functions), `store.py` (Supabase), `export.py`, `main.py` (CLI).
- `supabase/migrations/`: SQL that is applied manually in the Supabase SQL editor.
- `exports/news-latest.json`: generated by the collector (last 30 days). Don't edit it by hand.
- `.github/workflows/collect.yml`: runs every 3 hours and commits the export when it changes.

## Commands (from `collector/`)
- Tests: `python -m pytest -q`
- Dry run: `python -m gamedap_collector.main --dry-run [--game vampir]`
- Real run: `python -m gamedap_collector.main`

## Notes
- Secrets come from env (`DISCORD_BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_SECRET_KEY`), loaded from the repo-root `.env` when it exists. Never log or hardcode them.
- Dedupe is by `content_hash` (sha256 of game id + normalized body). The first row seen wins (`ignore_duplicates`).
- `collector_state` advances only after a successful upsert.
- item_type: the origin channel name wins first, then keywords in the title, then keywords in the body.
- Forwards (`message_snapshots`) don't carry the source channel name, so it comes from `origin_labels`.

## Git conventions
- No co-author or attribution lines in commits or PR descriptions (`.claude/settings.json` sets `attribution` to empty).
- Commit messages are short and natural and describe what changed. Use imperative mood, a lowercase type prefix (`feat`, `fix`, `chore`, `docs`, `test`, `refactor`), a subject of about 60 characters at most, no body unless it's really needed, and no emojis.
  - e.g. `feat: add discord collector with dedupe`, `fix: handle forwarded messages without content`
- Group related changes into one commit instead of many tiny ones.
